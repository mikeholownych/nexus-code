### A1 — P1: Session saves discard recovery and verification-baseline state

Locations: [session.ts:139](source/cli/src/session.ts#L139), [app.ts:265](source/cli/src/core/app.ts#L265), [repl.ts:281](source/cli/src/repl.ts#L281), [sidecar.ts:908](source/cli/src/sidecar.ts#L908).

Evidence: the captured regression file passed 4/4 with the initial uncommitted repairs; the same tests failed 4/4 against the final clean source. Failures cover round-trip recovery state, explicit-null preservation, REPL/sidecar forwarding and ApplicationCore forwarding. ### A2 — P1: Build/typecheck can evaluate different inputs from the candidate

Location: [runner.mjs:146](source/eval/evaluators/code/runner.mjs#L146), especially `sourceOverlayPath` and `createPinnedCandidateWorkspace`.
