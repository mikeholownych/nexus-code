## Blocking findings

### A1 — P1: Session saves discard recovery and verification-baseline state

Locations: [session.ts:139](source/cli/src/session.ts#L139), [app.ts:265](source/cli/src/core/app.ts#L265), [repl.ts:281](source/cli/src/repl.ts#L281), [sidecar.ts:908](source/cli/src/sidecar.ts#L908).

`saveSessionLocked` constructs a replacement durable record without `operation`, `providerRecovery`, or `changeBaseline`. Its application and interactive callers also omit those fields. Evidence: the captured regression file passed 4/4 with the initial uncommitted repairs; the same tests failed 4/4 against the final clean source. Failures cover round-trip recovery state, explicit-null preservation, REPL/sidecar forwarding and ApplicationCore forwarding. These are real save/load probes with controlled caller fixtures, not a live rate-limit/crash campaign.

Fix all writers and the serializer together, preserve absent versus explicit-null semantics, then prove real suspend/restart/resume with provider recovery, an operation, and a failing-test baseline. This confirms a previously tentative WP-1306 finding; it is not a new speculative concern.

### A2 — P1: Build/typecheck can evaluate different inputs from the candidate

Location: [runner.mjs:146](source/eval/evaluators/code/runner.mjs#L146), especially `sourceOverlayPath` and `createPinnedCandidateWorkspace`.

The evaluator copies the baseline and overlays only recognized syntax extensions. Candidate JSON, Go, C, CSS and other build inputs do not reach the evaluated workspace. Probe: candidate `data.json` was `invalid json`, while the evaluated copy remained the valid baseline `{"value":1}`. Conversely, a candidate `build.rs` was copied into the evaluated workspace. Define a checker-integrity policy separate from candidate-source coverage. Carry every relevant candidate addition, modification and deletion, or return an explicit unsupported/invalid evaluation. Pin trusted verifier helpers and configuration without silently substituting baseline program inputs. Reproduce false-pass and checker-tampering cases end to end before trusting benchmark scores.

### A9 — P2: Evaluator commands lack an explicit resource budget
