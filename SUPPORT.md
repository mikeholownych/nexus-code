# Getting help

Read the [quickstart](quickstart.md), [client guide](docs/CLIENT_GUIDE.md), [development guide](docs/DEVELOPMENT.md), and [provider setup](docs/CLOUD_PROVIDERS.md).

Ask usage and configuration questions in [GitHub Discussions](https://github.com/mikeholownych/nexus-code/discussions). Report reproducible defects using the [bug form](https://github.com/mikeholownych/nexus-code/issues/new?template=bug_report.yml). Include your version, operating system, Node.js version, installation method, minimal reproduction, and sanitized diagnostic output.

Never share API keys, tokens, private code, full environment dumps, or unredacted session logs. Review diagnostics before posting. Security issues belong in the private channel described in [SECURITY.md](SECURITY.md).

This is a community-maintained project. Support and fixes depend on maintainer availability; no service-level agreement is offered. Published releases and their notes are authoritative for availability. Development branches and planned v1 features are not a promise of a released product.
