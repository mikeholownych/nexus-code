## How to read the `passed: false`

The runner's pass rule requires, besides 99.5% native-valid calls, that every one of the five hybrid ("think before the call") attempts per tool carries reasoning. An alias served with reasoning off cannot satisfy that by construction; the runbook ([`docs/v1.1.4/G1.1-4-LIVE-MATRIX.md`](../../v1.1.4/G1.1-4-LIVE-MATRIX.md)) says so for `engineering/b0`, and the same applies to `interactive` and `lead`, which advertise `reasoning.mode: off`. The failed flag is therefore a statement about reasoning output these aliases are not configured to produce, not about tool-call validity. It is reported as the runner produced it; the evidence file was not edited and the rule was not changed to turn it green.
