# WP-1104: Standalone `nexus eval` command

## Specification

**User story:** As a Nexus operator, I need to run a versioned evaluation dataset through the installed Nexus executable and receive a structured score file, so that I can compare candidate builds reproducibly without depending on the source checkout.

**Acceptance criteria:**

- **AC1:** `nexus eval --help` exposes `--dataset`, `--split`, `--runs`, `--isolated-home`, and `--output`. Test: `eval CLI help exposes versioned dataset options`.
- **AC2:** A packaged candidate resolves and executes the installed CLI dispatch, runner, and scorer from its package closure when launched outside the source checkout, without inference for an empty benchmark split. Test: `packaged evaluator runtime executes outside checkout`.
- **AC3:** A versioned dataset run rejects unsupported `--limit` before creating the output directory or starting the runner; help states that `--limit` applies only to legacy runs. Test: `versioned eval rejects limit before runner or output creation`.
- **AC4:** An exact installed candidate run executes the six unique public benchmark tasks with no skips or missing tasks and records the binary SHA, split, and recomputed manifest SHA. Test: `installed candidate runs all public benchmark tasks with provenance`.
- **AC5:** Existing legacy dataset invocation and `--limit` behavior remain compatible. Test: `legacy eval invocation and limit remain supported`.

**Out of scope:** Adding evaluator kinds, changing the public dataset schema, changing legacy scoring, or publishing/tagging a release.

**Dependencies:** WP-1103 versioned dataset and runner foundation at `6adbeb31` and `00a8cb4d` on this branch. WP-1102 is not a functional dependency. WP-1108 is not imported as a branch; package changes will be based on the selected current package script and separately checked against its ownership and gate state.

**Files claimed:** `cli/src/eval_cli.ts`, `cli/src/index.ts`, `cli/test/eval_cli.test.ts`, `cli/scripts/run_tests.mjs`, `eval/README.md`, `eval/run.mjs`, `eval/runner_api.mjs`, `eval/package_runtime.test.mjs`, `scripts/stage_eval_runtime.mjs`, `scripts/package-linux.sh`, `docs/v1.1.0/WP-1104-PLAN.md`, and all paths in the accepted WP-1103 commits being integrated.
