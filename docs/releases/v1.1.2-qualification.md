# Nexus Code v1.1.2 Qualification Record

**Status as of 2026-11-04: v1.1.2 ships with known limitations that the owner accepted explicitly.** The release source head is `bd7fb1cf` on `v1/v112-release` (PR #402). ## Known limitations (owner waiver)

See [v1.1.2.md](v1.1.2.md#known-limitations-owner-waiver) for the full list. In short: the 99.5% constrained-decoding target was never measured against live providers; the server-kind cache has no expiry and can send `X-Task-Class` to a replaced non-gateway server; null normalisation misses repaired and text-mode tool calls; the code evaluators overlay only some file types onto the baseline workspace (so edits to other files are invisible to build and typecheck), can be shadowed through `node_modules` and build helpers, refuse very large workspaces, and have no resource limits. The evaluators are not used by any dataset task yet.
