# Nexus Code v1.1.2 Qualification Record

**Status as of 2026-11-04: v1.1.2 ships with known limitations that the owner accepted explicitly.** The release source head is `822c08fb` on `v1/v112-release` (PR #402). Its sources are the integration branch `v1/v112-wp1101-integration` through codex-root's `2dbe565b`, plus current `main`, plus the version bump from `1.1.2-rc.2` to `1.1.2` (`bd7fb1cf`), plus the `--step` parallel-read fix (`822c08fb`). **What this record does not claim.** Independent reviewers returned REQUEST CHANGES on the WP-1105 evaluator work and on the WP-1107 provider work; the owner waived the listed findings and fixed only one of them. Gate G1.1-4 (at least 99.5% valid tool-call JSON across supported provider endpoints) was **not measured** and is **not met**. No release package for the final stable version was built or installed by this record: the `rc.2` archive below was built from an earlier source (`c198a33f`), is unpublished, and does not qualify `v1.1.2`. The published archive is built by the release workflow on the tag.

The v1.1.0 release failed and published no release files. v1.1.1 is the immutable published predecessor. No `v1.1.2-rc.*` tag was ever published; the RC1 and RC2 archives named in this record are superseded local artifacts.

## Known limitations (owner waiver)

See [v1.1.2.md](v1.1.2.md#known-limitations-owner-waiver) for the full list. In short: the 99.5% constrained-decoding target was never measured against live providers; the server-kind cache has no expiry and can send `X-Task-Class` to a replaced non-gateway server; null normalisation misses repaired and text-mode tool calls; the code evaluators overlay only some file types onto the baseline workspace (so edits to other files are invisible to build and typecheck), can be shadowed through `node_modules` and build helpers, refuse very large workspaces, and have no resource limits. The evaluators are not used by any dataset task yet.
