# Nexus Code v1.0.0-rc.7 release candidate

**Maturity:** release candidate; prerelease, not stable.

**Status:** this candidate is for exact-artifact qualification. It does not establish independent acceptance or authorize stable v1.0.0 promotion. Qualification results must identify the workflow-produced package and its digest.

This release packages the Nexus Code Linux x86-64 client: the TypeScript CLI and sidecar, production Node dependencies, Rust `harness-core`, and Ratatui `nexus-tui`.

## Changes since RC6

- **Checkpoint recovery:** when a turn checkpoint cannot be saved, Nexus now asks how to proceed instead of silently changing permission mode or stopping without offering a choice. Depending on the failure, choices include read-only operation, continuing in the configured mode without a rollback checkpoint, retrying, cancelling, or entering a different instruction. If the user explicitly permits sensitive persistence and protected Git verification still fails, Nexus asks again; retry continues to use normal protected-Git verification.
- **Terminal output safety:** streamed assistant text and echoed task prompts are sanitized at the terminal display boundary, including split control sequences and secret redaction. Observer/model data remains unchanged.
- **Provenance reporting:** in automatic mode, the installer and upgrade attempt verification when a trusted GitHub CLI is available and report when verification cannot be performed. Set `NEXUS_VERIFY_ATTESTATION=1` to require verification or `=0` to skip it without the automatic-mode notice; empty or invalid values are rejected, and a shell setting takes precedence over `config.env`.

## Runtime requirements

- Linux x86-64 with glibc 2.35 or newer.
- Node.js 22 or newer.
- An OpenAI-compatible inference endpoint, local or explicitly selected provider.

The archive does not include Node.js. Rust and Cargo are not required at runtime. No other OS or architecture is claimed.
