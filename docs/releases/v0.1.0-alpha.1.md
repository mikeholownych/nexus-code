# Nexus Code v0.1.0-alpha.1 alpha release candidate

**Maturity:** alpha, pre-1.0 SemVer prerelease.

**Status:** candidate prepared; no GitHub Release has been published.

This initial 0.x release uses an alpha prerelease identifier to show that the client is still in early development. It is not the latest stable version; install it by pinning `NEXUS_VERSION=v0.1.0-alpha.1` after publication.

This package is the complete Nexus Code Linux client: TypeScript CLI/sidecar, production Node dependencies, Rust `harness-core`, and Ratatui `nexus-tui`.

## Runtime requirements

- Linux x86-64 with glibc 2.35 or newer.
- Node.js 20 or newer.
- An OpenAI-compatible inference endpoint, local or explicitly selected provider.

The archive does not include Node.js. Rust and Cargo are not required at runtime. No other OS or architecture is claimed.

## Candidate assets

- `nexus-linux-x86_64-v0.1.0-alpha.1.tar.gz`
- `SHA256SUMS`

The release workflow builds the versioned archive and checksum from a matching `v0.1.0-alpha.1` tag. These asset names must be verified against the successful CI run before publication.

Install and configuration instructions are in [quickstart.md](../../quickstart.md). The public installer remains pending until these assets are published and the public download path has been verified.
