# Nexus Code v1.0.0-rc.3 release candidate

**Maturity:** release candidate; prerelease, not stable.

**Status:** this candidate is for exact-artifact qualification. It does not establish independent acceptance or authorize stable v1.0.0 promotion. Qualification results must identify the workflow-produced package and its digest.

This release packages the Nexus Code Linux x86-64 client: the TypeScript CLI and sidecar, production Node dependencies, Rust `harness-core`, and Ratatui `nexus-tui`.

## Changes since RC2

- Raises the supported Node.js runtime floor to 22, as required by DEC-12.
- Adds an interactive checkpoint decision when sensitive content cannot be persisted, allowing the user to choose read-only, continue without a rollback checkpoint, create a checkpoint after acknowledging the sensitivity warning, cancel, or revise the instruction. This behavior must be verified from the installed candidate; RC1 and RC2 do not contain it.
- Makes `nexus doctor` state-integrity scanning asynchronous and bounded. The default integrity check has a bounded 30-second minimum window for large stores; an explicitly supplied `--timeout` remains authoritative. The check recognizes schema-2 task message-log cursors, excludes the session index from conversation validation, and treats unlisted models as unverified until a successful `--deep` inference check.

These source changes and their CI results do not replace RC3 artifact checks or installed-package qualification.

## Runtime requirements

- Linux x86-64 with glibc 2.35 or newer.
- Node.js 22 or newer.
- An OpenAI-compatible inference endpoint, local or explicitly selected provider.

The archive does not include Node.js. Rust and Cargo are not required at runtime. No other OS or architecture is claimed.

## Candidate assets

The release workflow for `v1.0.0-rc.3` is expected to produce the version-matched Linux archive, `SHA256SUMS`, SBOM, notices, installer, and provenance. The workflow run, tag commit, artifact digests, and qualification evidence must be recorded before this candidate can be accepted. Local builds are not interchangeable with the workflow-produced artifacts.
