# Nexus Code v1.1.3-rc.1 (release candidate)

**Maturity:** Release notes for Nexus Code v1.1.3. This release carries the **entire v1.1.2 scope, unchanged**, under the version number v1.1.3.

## Why v1.1.3 and not v1.1.2

The `v1.1.2` tag was pushed on `bbd7db46` (the merge of #403), but the Release workflow rejected it: a stable tag must be a version-only commit directly on a `vX.Y.Z-rc.N` tag, and no `v1.1.2-rc.N` tag existed. The workflow failed before packaging, so **nothing was published for v1.1.2**. Version tags are immutable, so `v1.1.2` stays on that commit as an unreleased tag and the same source ships as `v1.1.3-rc.1`, then `v1.1.3` (a version-only promotion).

## What is in this release

Everything in [v1.1.2](v1.1.2.md): WP-1101 to WP-1108 (WP-1107 in reduced scope), non-progress recovery, specialist orchestration, and the fixes for the multi-message resume and the `--step` parallel-read pause. The known limitations listed there, including the unmeasured 99.5% valid-tool-call target (G1.1-4) and the sequential-path `--step` stagnation overwrite, **apply unchanged** to v1.1.3. The qualification record for the source is [v1.1.2-qualification.md](v1.1.2-qualification.md); the only difference between the qualified source and this release is the version number and these notes.

Planned work that was scheduled as v1.1.3 (the findings ledger and the Worktrunk integration) moves to v1.1.4.
