# Nexus Code v1.0.0-rc.1 release candidate

**Maturity:** release candidate; prerelease, not stable.

**Status:** prepared for exact-artifact qualification. This candidate does not establish independent acceptance or authorize stable v1.0.0 promotion. Qualification results will be recorded against the workflow-produced artifact and its digest.

This candidate packages the Nexus Code Linux x86-64 client: the TypeScript CLI and sidecar, production Node dependencies, Rust `harness-core`, and Ratatui `nexus-tui`. It is intended to exercise the version-matched package, installer, supply-chain outputs, and the required provider, standalone, held-out, cross-runner, and terminal qualification gates.

## Candidate changes

The v1.0.0 candidate includes the product, security, continuity, provider, terminal, and packaging work accumulated since the 0.1.0 alpha releases. See the repository changelog for the implemented feature summary. Release-critical behavior remains subject to the exact-RC acceptance process in [`ACCEPTANCE.md`](../v1.0.0/ACCEPTANCE.md).

## Runtime requirements

- Linux x86-64 with glibc 2.35 or newer.
- Node.js 20 or newer. Node.js 20 remains the v1.0.0 compatibility floor, but reached upstream end of life on 2026-04-30 per the [Node.js Release Working Group schedule](https://github.com/nodejs/Release/blob/main/README.md#release-schedule); use a maintained release such as Node.js 22 or 24 for security updates.
- An OpenAI-compatible inference endpoint, local or explicitly selected provider.

The archive does not include Node.js. Rust and Cargo are not required at runtime. No other OS or architecture is claimed.

## Candidate assets

The release workflow builds the version-matched archive, `SHA256SUMS`, SBOM, notices, installer, and provenance for tag `v1.0.0-rc.1`. The workflow outputs and their digests are the qualification candidate; a local build is not interchangeable.
