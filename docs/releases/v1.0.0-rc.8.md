# Nexus Code v1.0.0-rc.8 release candidate

**Maturity:** release candidate; prerelease, not stable.

**Status:** this candidate is for exact-artifact qualification. It does not establish independent acceptance or authorize stable v1.0.0 promotion. Qualification results must identify the workflow-produced package and its digest.

This release packages the Nexus Code Linux x86-64 client: the TypeScript CLI and sidecar, production Node dependencies, Rust `harness-core`, and Ratatui `nexus-tui`.

## Changes since RC7

- **Checkpoint safety:** checkpoint creation now detects a present or unreadable Git index lock before publishing a checkpoint reference, and reports why it stopped. It rechecks the lock after validation and stash creation so a concurrent Git operation is less likely to publish a stale checkpoint.
- **Read-only mode consistency:** the effective permission posture is applied consistently when an agent and its workspace extensions start or change modes. A temporary checkpoint-safety fallback stays separate from the configured mode, allowing recovery without silently changing the operator's selected mode.
- **Recovered operation continuity:** recovered operation context is retained across session restoration, while prior verifier baselines remain untrusted and require fresh verification before a recovered result can be treated as verified.

## Runtime requirements

- Linux x86-64 with glibc 2.35 or newer.
- Node.js 22 or newer.
- An OpenAI-compatible inference endpoint, local or explicitly selected provider.

The archive does not include Node.js. Rust and Cargo are not required at runtime. No other OS or architecture is claimed.

## Candidate assets

The release workflow for `v1.0.0-rc.8` is expected to produce the version-matched Linux archive, `SHA256SUMS`, SBOM, notices, installer, and provenance. The workflow run, tag commit, artifact digests, and qualification evidence must be recorded before this candidate can be accepted. Local builds are not interchangeable with the workflow-produced artifacts.
