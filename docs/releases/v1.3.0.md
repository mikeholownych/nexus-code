# Nexus Code v1.3.0

**This file is the stable-release notes for v1.3.0 and is written together with the release candidate.** The release workflow requires a stable tag to be a version-only commit directly on its release candidate, so these notes cannot change after [`v1.3.0-rc.1`](v1.3.0-rc.1.md) is tagged; if they need to change, the next candidate carries the change.

**Maturity:** external qualification is pending when this file is written. A stable tag does not by itself record a qualification result; the owner's decision to promote the candidate, and any qualification evidence behind it, belong in `docs/evidence/` and the release page, not in this file. This is not a claim that Nexus Code is frontier-grade.

What is in this release, what is not, the behaviour changes that need a migration note, the security limits and the evidence: [`v1.3.0-rc.1.md`](v1.3.0-rc.1.md) applies unchanged, because a stable v1.3.0 differs from the candidate by its version strings only. Per-unit status and the independent-review record: [`v1.3.0-READINESS.md`](v1.3.0-READINESS.md). Plan: [`docs/v1.3.0/PLAN.md`](../v1.3.0/PLAN.md). Previous stable release: [`v1.2.2`](v1.2.2.md).
