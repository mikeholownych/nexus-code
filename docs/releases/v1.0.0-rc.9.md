# Nexus Code v1.0.0-rc.9 release candidate

**Maturity:** release candidate; prerelease, not stable.

**Status:** this candidate is for exact-artifact qualification. It does not establish independent acceptance or authorize stable v1.0.0 promotion. Qualification results must identify the workflow-produced package and its digest.

This release packages the Nexus Code Linux x86-64 client: the TypeScript CLI and sidecar, production Node dependencies, Rust `harness-core`, and Ratatui `nexus-tui`.

## Changes since RC8

- **Verifier baseline timing:** capture the discovered verifier baseline before the first workspace-mutating tool runs. This preserves the pre-mutation state for verification across both direct commands and subagent dispatch.
- **Upgrade download recovery:** retry one idempotent release download after a connection reset before a response, within the existing timeout. HTTP errors, origin and checksum validation, archive handling, and recovery behavior remain unchanged.
- **Provider stream handling:** preserve provider output and error-code semantics for streamed and non-streamed responses, avoid unsafe immediate failover after partial output, retain cancellation and watchdog cleanup while reading error bodies, and bound and redact provider error text.

## Runtime requirements

- Linux x86-64 with glibc 2.35 or newer.
- Node.js 22 or newer.
- An OpenAI-compatible inference endpoint, local or explicitly selected provider.

The archive does not include Node.js. Rust and Cargo are not required at runtime. No other OS or architecture is claimed.

## Candidate assets

The release workflow for `v1.0.0-rc.9` is expected to produce the version-matched Linux archive, `SHA256SUMS`, SBOM, notices, installer, and provenance. The workflow run, tag commit, artifact digests, and qualification evidence must be recorded before this candidate can be accepted. Local builds are not interchangeable with the workflow-produced artifacts.
