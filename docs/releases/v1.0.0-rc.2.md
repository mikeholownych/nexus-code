# Nexus Code v1.0.0-rc.2 release candidate

**Maturity:** release candidate; prerelease, not stable.

**Status:** this candidate is for exact-artifact qualification. It does not establish independent acceptance or authorize stable v1.0.0 promotion. Qualification results must identify the workflow-produced package and its digest.

This release packages the Nexus Code Linux x86-64 client: the TypeScript CLI and sidecar, production Node dependencies, Rust `harness-core`, and Ratatui `nexus-tui`.

## Changes since RC1

- Release SBOM generation now calculates the Rust production dependency closure for the shipped Linux target and fails on ambiguous or incomplete component references before combining it with the Node SBOM.
- Evaluator qualification setup resolves the configured Go toolchain ahead of its host fallback, with regression coverage for toolchain selection and isolation checks.
- CI provisions Go 1.22 and a bounded temporary filesystem for evaluator fixtures.

These source changes and their CI results do not replace RC2 artifact checks or installed-package qualification.

## Runtime requirements

- Linux x86-64 with glibc 2.35 or newer.
- As tagged, this candidate declares Node.js 20 or newer. Node.js 20 reached upstream end of life on 2026-04-30, and DEC-12 now requires Node.js 22 or newer for v1.0.0, so `v1.0.0-rc.2` is not promotable to v1.0.0; a later candidate carries the Node.js 22 floor.
- An OpenAI-compatible inference endpoint, local or explicitly selected provider.

The archive does not include Node.js. Rust and Cargo are not required at runtime. No other OS or architecture is claimed.

## Candidate assets

The release workflow for `v1.0.0-rc.2` produces the version-matched Linux archive, `SHA256SUMS`, SBOM, notices, installer, and provenance. The workflow run, tag commit, artifact digests, and qualification evidence must be recorded before this candidate can be accepted. Local builds are not interchangeable with the workflow-produced artifacts.
