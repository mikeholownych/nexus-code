# Nexus Code v1.0.0-rc.15 release candidate

**Maturity:** release candidate; prerelease, not stable.

**Status:** this candidate is the final release qualification candidate for stable v1.0.0 promotion.

This release packages the Nexus Code Linux x86-64 client: the TypeScript CLI and sidecar, production Node dependencies, Rust `harness-core`, and Ratatui `nexus-tui`.

## Changes since RC14

### Qualification evidence and release candidate alignment
- Integrates all Gate 6 qualification evidence packets: scripted installed-RC PTY scenarios (ACCEPTANCE §5.2), complete provider receipts, synthetic-journal and checksum-tamper durability cells, cross-runner builds, and comprehensive Gate 10 disclosures.
- Includes narrow composer hints in the live TUI layout (PR #359).
- Resolves latent test suite assumption in `cli/test/upgrade_tui.test.ts` to accommodate both upgrade-available and up-to-date assertions across prerelease and stable lifecycle transitions (PR #363).

## Runtime requirements

- Linux x86-64 with glibc 2.35 or newer.
- Node.js 22 or newer.
- An OpenAI-compatible inference endpoint, local or explicitly selected provider.

The archive does not include Node.js. Rust and Cargo are not required at runtime. No other OS or architecture is claimed.

The release workflow for `v1.0.0-rc.15` produces the version-matched Linux archive, `SHA256SUMS`, SBOM, notices, installer, and provenance.
