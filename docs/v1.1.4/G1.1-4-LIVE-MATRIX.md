# G1.1-4 live measurement runbook (tool grammar matrix)

**Owner constraint (DEC-16, 2026-10-14; restated 2026-11-13):** there are no separate llama.cpp, vLLM or Ollama servers. All live inference goes through the homelab-ai gateway (`https://10.0.8.5:8443/v1`); direct worker access is not allowed and no separate host or GPU may be proposed. This runbook therefore measures gateway-routed model aliases. Per-kind behaviour is qualified separately by `eval/standalone/plain_proxy.mjs` profiles and the CI server-kind conformance fixtures.

Status: **run 2026-11-13 on the `1.1.4-rc.1` archive; G1.1-4 NOT MET** (`engineering/deep` 155/200, `engineering/lead-reasoning` 150/200 native valid). Evidence: `docs/evidence/v1.1.4/wp-1107-provider-matrix.json`; analysis in `docs/v1.1.4/FINDINGS.md` (WP-1107 and I-5 rows). Any later claim needs a new run at the exact head.

## What it measures
`eval/tool_grammar_matrix.mjs` drives the **exact installed candidate client** against each gateway model alias in the config: 200 attempts per alias (50 per allow-listed tool, 5 of them hybrid `<think>` attempts). An alias passes only with `native_valid * 1000 >= attempts * 995`, zero schema-invalid and zero invalid. It writes immutable JSON evidence plus a detached `.sha256`.

## What it now binds (v1.1.4)
- the candidate **archive**: `archiveSha256` pin is mandatory and compared to the file;
- the installed runtime: every file matches the archive's `MANIFEST.sha256`; `.provenance.json` names the same archive digest and commit;
- the **checkout content**: `sourceTree` (the pinned `git rev-parse HEAD^{tree}`) is mandatory, the checkout's tree must equal it, every tracked file is re-hashed from disk against its blob id (defeats `assume-unchanged` / `skip-worktree`), its executable bit must equal the tree mode whatever `core.fileMode` says, untracked or ignored files are rejected, and `git replace` refs are rejected (every git call runs with `--no-replace-objects`). The evidence records `sourceCommit` and `sourceTree`.

## Steps
1. **Claim the shared inference host** (one host, DEC-16). The claim is machine-local and atomic and follows `docs/v1.0.0/CONCURRENCY.md` sections 2 and 3: `mkdir` is the lock, `owner.json` is JSON, and the release is logged.
   ```sh
   CLAIMS="$(git rev-parse --path-format=absolute --git-common-dir)/nexus-claims"; mkdir -p "$CLAIMS"
   REF="$(git branch --show-current)"; REF="${REF:-$(git rev-parse --short HEAD)}"   # detached worktree: record the short sha
   OUTCOME=aborted
   release_gateway() {   # runs on every exit path, including abort; logs one line, then releases
     printf '%s GATEWAY released by %s: G1.1-4 matrix %s\n' "$(date -u +%FT%TZ)" "$AGENT_NAME" "$OUTCOME" >> "$CLAIMS/../nexus-claims.log"
     rm -r "$CLAIMS/GATEWAY"
   }
   if mkdir "$CLAIMS/GATEWAY" 2>/dev/null; then
     trap release_gateway EXIT
     trap 'exit 130' INT TERM
     if ! printf '{"agent":"%s","branch":"%s","since":"%s","pid":%s}\n' \
          "$AGENT_NAME" "$REF" "$(date -u +%FT%TZ)" "$$" > "$CLAIMS/GATEWAY/owner.json"; then
       echo "claim directory created but owner.json could not be written; releasing the claim" >&2; exit 1
     fi
   else
     echo "GATEWAY is already claimed by: $(cat "$CLAIMS/GATEWAY/owner.json" 2>/dev/null || echo unknown)" >&2; exit 1
   fi
   ```
   Run the matrix (step 5) in this same shell and set `OUTCOME=pass` or `OUTCOME=fail` from its exit status before the shell exits. The `EXIT` trap then logs the line and removes the claim even if the run is interrupted or you `cd` elsewhere (`$CLAIMS` is absolute). If you cannot keep one shell, run the two lines inside `release_gateway` by hand at the end, with the outcome `pass`, `fail` or `aborted`.

   Do not run while another agent holds the claim. A claim older than 24 h whose PID is gone may be broken only as CONCURRENCY.md section 2 describes (record it in the log first).

   **Isolation (CONCURRENCY.md section 3).** Run from a dedicated `git worktree` of the exact head (not a shared checkout), with a throwaway `HOME` so the run never reads `~/.config/nexus/credentials.json` or writes sessions into the operator's home:
   ```sh
   git worktree add ../nexus-wt-g114 <exact-head-sha>
   export HOME="$(mktemp -d)"
   ```
   The private config carries endpoints only; if an endpoint needs a key, supply it through the environment of the run, never in the config or the repo.

2. **Build the candidate** from the exact head under test; the checkout must be clean at that head and contain no untracked or ignored files. Record: `sourceCommit=$(git rev-parse HEAD)`, `sourceTree=$(git rev-parse HEAD^{tree})`.
3. **Install it** with the real installer so `.provenance.json` (`method: installer`, `archiveSha256`, `revision`) is written, and keep the archive: `archiveSha256=$(sha256sum nexus-<version>.tar.gz | cut -d' ' -f1)`.
4. **Write a private config** (outside the repo, mode 0600; it names endpoints only, never credentials; the key is read from the environment variable named by `apiKeyEnv`):
   ```json
   {
     "archivePath": "/abs/nexus-<version>.tar.gz",
     "archiveSha256": "<sha256>",
     "installRoot": "/abs/installed/nexus",
     "candidateCheckoutRoot": "/abs/checkout",
     "sourceCommit": "<40 hex>",
     "sourceTree": "<40 hex>",
     "outputPath": "/abs/docs/evidence/v1.1.4/wp-1107-provider-matrix.json",
     "providers": [
       { "provider": "gateway", "serverKind": "gateway", "endpointUrl": "https://10.0.8.5:8443/v1", "apiKeyEnv": "NEXUS_GATEWAY_KEY",
         "serverVersion": "<limits_version>", "modelName": "<alias>", "contextSize": 8192,
         "sampling": { "temperature": 0, "max_tokens": 1024 }, "toolChoice": "auto", "serverFlags": [], "compatibilityMode": "gateway-openai-chat" }
       // one entry per alias: at least one, no repeated modelName, never mixed with direct-server entries
     ]
   }
   ```
   The gateway attests neither an image nor a model digest, so a gateway entry omits `imageDigest` and `modelDigest` (one that is present must still be a well-formed `sha256:` digest). `serverVersion` is the gateway's current `limits_version` from `/v1/models`. Before an alias's attempts the run compares it with the advertised value and stops with no evidence written if they differ; attempts already spent on earlier aliases are discarded. The evidence records the advertised `workers`. The matrix also refuses to start unless every other pinned field is present and the endpoint identifies as `gateway`.

   A pass means the gateway-routed alias meets the 99.5% bar through the installed client; it is not evidence about any individual llama.cpp, vLLM or Ollama build.

   Direct-server mode (not available in this environment): exactly three entries (`llamacpp`, `vllm`, `ollama`), each with `serverVersion`, `imageDigest`, `modelName`, `modelDigest` and the endpoint identifying as its kind.
5. **Run:**
   ```bash
   node eval/tool_grammar_matrix.mjs --config /abs/private-config.json
   ```
   Exit 0 only if every endpoint passes. Stdout is a non-secret summary.
6. **Commit the evidence** (`outputPath` and its `.sha256`), reference it from the release notes, update the `G1.1-4` row in `FINDINGS.md` with the exact integer counts, and release the `GATEWAY` claim.

If an endpoint misses, the evidence is still written as a failed result; G1.1-4 stays NOT MET and the miss is reported, not rounded.

## Gateway run notes 

- **Pacing.** The gateway answers HTTP 429 (`request rate limit exceeded`) after about 60 rapid requests. Set `requestIntervalMs` , `rateLimitRetries` and `rateLimitDelayMs` on the provider; the evidence records `requestIntervalMs` and `throttledRetries`. An exhausted retry budget still counts as invalid.
- **Reasoning channel.** For `provider: "gateway"` the hybrid-reasoning count accepts a non-empty `reasoning_content` field as well as a `<think>` block in `content`; direct providers still need the `<think>` block. Reasoning aliases (`engineering/deep`, `engineering/lead-reasoning`) are required for the hybrid check; `engineering/b0` has reasoning off and cannot pass it.
- **Completion allowance.** Use `sampling.max_tokens` of the real client's 8192 for reasoning aliases; at 1024 reasoning consumes the whole budget (`finish_reason=length`).
- **Release archives.** The one relative `lib/cli/node_modules/.bin/*` symlink a release archive ships is accepted when it stays inside `lib/cli/node_modules/`, its target is in the manifest, and the installed link equals the archive link. Any other link is still rejected.
- **Install.** The matrix requires an install made by `install.sh` (provenance `method: "installer"`); an `upgrade`-method install is rejected.
